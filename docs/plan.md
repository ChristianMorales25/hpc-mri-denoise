## Experiments (maps to the course's "Common Requirements")

- **Runtime / speedup / efficiency**: seq vs OpenMP vs CUDA for each filter.
- **Strong scaling**: fixed volume, OpenMP threads 1, 2, 4, 6, 8, 12.
- **Weak scaling**: synthetic volume size grows with thread count
  (constant voxels per thread).
- **Problem size**: 64³, 96³, 128³, 181×217×181 (BrainWeb), 256³.
- **GPU configuration**: block shapes, shared memory on vs off.
- **Memory-transfer cost**: H2D/kernel/D2H split, and how it shrinks
  relative to compute as the work per voxel grows (bilateral → NLM).
- **Quality**: PSNR/SSIM vs noise level (3–9 %) and filter parameters; Dice
  of the downstream segmentation with and without denoising.
- **Correctness**: every parallel version checked against the sequential
  baseline (`evaluate.py --ref`).

## Known caveats to discuss in the report

- Whole-volume metrics are dominated by background, where Rician noise has a
  non-zero mean that no filter here removes; tissue-masked metrics are the
  primary ones.
- Laptop GPU: thermal throttling and the ~2 s TDR kernel limit under WSL2.
- `--use_fast_math` on the GPU gives differences around 1e-6 from the CPU.

## Smoke-test baseline (96³ synthetic, 5 % noise, Oct 28)

Single runs, so expect some noise in the numbers.

| Filter | seq | OpenMP (12 thr) | CUDA naive (total / kernel) |
|---|--:|--:|--:|
| Bilateral r=2 | 1033 ms | 220 ms | 2.8 / 1.1 ms |
| Diffusion 20 it | 837 ms | 216 ms | 2.2 / 1.0 ms |
| NLM S=2 P=1 | 22.7 s | 4.0 s | 26.6 / 25.2 ms |

Tissue PSNR: noisy 27.4 dB → bilateral 33.7, diffusion 30.2, NLM 38.0.

NLM S=5 P=1 on 192³ (CUDA naive): 1.72 s kernel with 16-slice chunks,
1.88 s unchunked. The unchunked launch is already close to the ~2 s TDR
limit, so chunking stays on by default (`--chunk 16`); its overhead is small.
